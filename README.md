# @igaozp/dsh-font-settings

为 DeepSeek Harness（DSH）添加字体设置

## 安装

### 在界面中安装

打开 DSH 的「插件」页面，选择「添加插件」，输入 `@igaozp/dsh-font-settings` 并确认安装。

### 通过命令行安装

```sh
dsh plugin --profile demo add @igaozp/dsh-font-settings
```

将 `demo` 替换为你使用的配置名称。

## 使用

打开「设置 → 通用设置」，找到「字体」，分别选择「界面字体」和「代码字体」，选择后立即生效；
